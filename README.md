# Mutual Fund Analytics

## Objective
Analyze mutual fund performance using ETL, SQL, Python, Power BI, and Advanced Analytics.

## Technologies
- Python
- Pandas
- NumPy
- SQLite
- SQL
- Power BI
- Matplotlib
- Jupyter Notebook

## Project Modules
- ETL Pipeline
- Data Cleaning
- Exploratory Data Analysis
- Performance Analytics
- Power BI Dashboard
- Advanced Analytics
- Mutual Fund Recommendation Engine

## Dashboard Pages
1. Industry Overview
2. Fund Performance
3. Investor Analytics
4. Portfolio Holdings
5. Benchmark Analysis

## Key Features
- 46,000 NAV Records
- 32,778 Investor Transactions
- 40 Mutual Fund Schemes
- Interactive Power BI Dashboard
- Value at Risk (VaR)
- Cohort Analysis
- Recommendation System
